# Drivers del lector ZKTeco

El driver de ZKFinger se instala por separado del ejecutable principal.

1. Ejecuta `setup.exe` como administrador.
2. Reinicia Windows si el instalador lo solicita.
3. Conecta el lector ZKTeco.
4. Verifica que la aplicación pueda detectar `zkfp.dll`.

No se ejecuta el instalador automáticamente para evitar cambios inesperados
en Windows y permitir que el técnico controle la instalación del controlador.
